📊 Basic Experiments

1. Noise Sweep Analysis

Category: Performance Analysis

Description: Systematically varies noise levels in quantum channels and measures impact on key generation rates and QBER.

Parameters Tested: Depolarization noise from 0% to 20% in 2% increments

Output: CSV file with noise vs. key rate, QBER data; visualization plots

2. Monte Carlo Simulation

Category: Statistical Analysis

Description: Runs multiple BB84 protocol instances with random initial states to compute statistical properties of generated keys.

Parameters: 100 protocol runs, 256 randomly initialized states

Output: Mean/std deviation of key rates, average QBER, success metrics

3. Attack Analysis

Category: Security Assessment

Description: Simulates eavesdropping scenarios using intercept-resend strategy with measurement basis randomization.

Attack Types: Individual photon attacks, coordinated attacks

Output: Eavesdropper detection probability, information gained by Eve, protocol resilience

4. Statistical Analysis

Category: Data Analysis

Description: Comprehensive statistical tests on generated keys including randomness, correlation, and entropy analysis.

Tests: Chi-square, t-tests, entropy calculation, autocorrelation

Output: Randomness quality metrics, statistical test results

🔐 Core Systems Analysis

5. Security Deep Dive

Category: Information Theory Analysis

Description: Detailed security analysis using information-theoretic bounds and finite-key analysis.

Metrics: Channel capacity, mutual information, secret key rate

Analysis: Asymptotic security, finite-key bounds, practical key rates

Output: Comprehensive security report with visualizations

6. Error Correction Demo

Category: Channel Reliability

Description: Demonstrates error correction (reconciliation) algorithms to recover shared keys from noisy quantum channels.

Features: Syndrome decoding, LDPC codes simulation

Metrics: Correction success rate, information leakage, efficiency

Output: Before/after error rates, reconciliation overhead

7. Decoy State Analysis

Category: Enhanced Security

Description: BB84 with decoy states to defend against photon number splitting attacks.

Features: Decoy state generation, security against PNS attacks

Parameters: Signal, decoy, vacuum state preparation

Output: Security improvement metrics, attack resilience analysis

8. Privacy Amplification

Category: Key Compression & Purification

Description: Applies privacy amplification techniques to reduce any potential eavesdropper information.

Methods: XOR-based compression, SHA256 hashing

Impact: Reduces key material by ~50% while eliminating information leakage

Output: Key compression ratio, security improvement

9. Secure Communication End-to-End

Category: Practical Implementation

Description: Complete integration of QKD-generated keys with AES encryption for secure message transmission.

Steps: Key generation → Privacy amplification → AES-256 encryption

Features: Message encryption/decryption, key schedule generation

Output: Encrypted/decrypted message demo, performance metrics

⚡ Advanced Features

10. Advanced Attack Scenarios

Category: Security Testing

Description: Simulates multiple sophisticated attack strategies against the protocol.

Attack Strategies:

  • Intercept-Resend (IR): Direct measurement and resending
  • Photon Number Splitting (PNS): Attacks on weak coherent pulses
  • Trojan Horse (TH): Auxiliary quantum state injections

Metrics: Detection probability, Eve's mutual information, protocol security

11. Randomness Quality Analysis

Category: Key Quality Assessment

Description: Tests generated keys against NIST and Diehard randomness test suites.

Tests Performed:

  • Frequency test (monobit)
  • Runs test (consecutive bits)
  • Autocorrelation analysis
  • Entropy calculation
  • Chi-square goodness-of-fit

Output: NIST compliance report, quality score

❓ Frequently Asked Questions

What is BB84?

BB84 is the first quantum key distribution protocol, developed by Bennett and Brassard in 1984. It enables two parties to generate identical random keys secure against eavesdropping by leveraging the principles of quantum mechanics.

Why 16 qubits?

16 qubits balance practical simulation performance with sufficient complexity to demonstrate protocol behavior. This allows experiments to complete in reasonable time on standard computing hardware while maintaining scientific accuracy.

What noise model is used?

The framework uses Qiskit's depolarizing channel, which realistically models quantum channel imperfections including spontaneous emission and dephasing effects at 0-20% noise levels.

Can I modify experiments?

Yes! All experiment source code is available in the experiments/ directory. You can fork, modify, and extend any experiment to suit your research needs.

How long do experiments run?

Basic experiments (Noise Sweep, Monte Carlo) typically complete in 30-60 seconds. Advanced experiments (Security Deep Dive, Attack Analysis) may take 1-3 minutes depending on system performance.

What are typical secret key rates?

Under ideal conditions (0% noise), the protocol achieves ~50% of raw generated bits as final secret key. Under 10% noise with error correction and privacy amplification, this drops to ~20-30% of raw bits.
